# Universal Engine Dock の導入方法

**日本語** | [English](INSTALL.en.md)

ぷよぷよ・テトリスの思考エンジン(AI)の手を「ぷよぷよテトリス2」に表示する Universal Engine Dock を、
Windows に入れて支援モードを始めるまでの手順です。
自作・公開の思考エンジンを足す方法は [ENGINE_SPEC.md](ENGINE_SPEC.md) を見てください。

## 1. 必要なもの

| 項目 | 内容 |
|---|---|
| OS | Windows 10(バージョン 2004 以降)/ 11 の 64bit |
| ゲーム | Steam 版「ぷよぷよテトリス2」(ウィンドウ表示) |
| CPU | 同梱の YamaNEKO には BMI2 命令のある CPU(Intel は第4世代 Core 以降、AMD は Ryzen 以降が目安) |
| 権限 | 管理者権限は要りません |

Python などを別に入れる必要はありません。

## 2. 入れる

1. Releases から `UniversalEngineDock-<版>.zip` をダウンロードする
2. zip が本物かを確かめる(任意)。PowerShell で次を実行し、リリースのページに書いてある SHA-256 と比べる

   ```powershell
   Get-FileHash .\UniversalEngineDock-0.1.0.zip
   ```

3. 確かめたら、**展開する前に** zip を右クリック →「プロパティ」→「許可する」にチェック →「OK」
   (中のファイルが「インターネットから入れたファイル」の扱いにならず、警告が出にくくなります。項目が無ければ不要です)
4. zip を好きな場所に展開する。設定を同じフォルダの `config/` に書くので、`Program Files` の中は避ける
5. `UniversalEngineDock.exe` を起動する。exe だけを別の場所へ移すと動きません(デスクトップに置くならショートカットを作る)

### 警告が出たら

| 出るもの | 対応 |
|---|---|
| 「Windows によって PC が保護されました」(SmartScreen) | 「詳細情報」→「実行」 |
| ノートンなどが起動を止めて調べる | 調べ終わるのを待って起動し直す。思考エンジンの exe(`engines/` の中)も最初の1回に調べられることがある |
| exe が隔離された | 2 の SHA-256 が合っていることを確かめたうえで、セキュリティソフトの「復元」と「除外」に、展開したフォルダを入れる |

SHA-256 が合わない時は使わず、Releases からダウンロードし直してください。

## 3. 支援モードを始める

1. ゲームを**ウィンドウ表示**で起動する。16:9 の大きさなら、盤面の位置は自動で決まる
   (「ゲームのウィンドウの大きさ」を選び「この大きさに合わせる」を押すと、その大きさに揃う)
2. 「ゲームのウィンドウを検出」を押す。見つからない時は一覧から選ぶ(選んだものは覚える)
3. 「対戦モード」か「一人用モード」のタブを選ぶ
4. サイド(1P・2P、または一人用)ごとに、ゲーム種別(ぷよ / テトリス / 支援なし)と思考エンジンを選ぶ
5. 「支援モード開始」を押す。思考エンジンの準備に数十秒かかることがある
6. やめる時は、ゲームの上に出る「支援モードを終了」を押す

支援モードの間、メイン画面は隠れます。ゲームのウィンドウを動かすと支援モードは止まるので、始め直してください。

### 画面に出るもの

- **丸(ドット)** — 次の一手を置くマス
- **情報パネル** — エンジンの狙い、連鎖の見込みなど

これらの表示は、画面の取り込みには写りません。配信・録画に出す時は「OBS に表示を出す」を使ってください(「プラグイン…」で OBS 出力を有効にする)。

### キャプチャボードで使う時

ゲームのウィンドウが無い時は、「ぷよ(テトリス)のキャリブレーション(キャプチャボード対応)」を押し、画面の案内に沿って盤面や HOLD・NEXT などの位置をクリックします。
映像の色や縁の付き方によっては、正しく読めないことがあります。

### プラグインを足す

1. 「プラグイン…」を押し、「フォルダを開く」で `plugins/` を開く
2. プラグインのフォルダ(中に `plugin.py` があるもの)を、そのまま `plugins/` に置く
3. 「保存して再起動」を押す。Universal Engine Dock が閉じて起動し直し、足したプラグインを読み込みます

プラグインは起動した時に読み込むので、置いただけでは使えません。置いた後に「プラグイン…」を開くと、そのことを出します。

## 4. 困った時

| 症状 | 確かめること |
|---|---|
| ウィンドウが見つからない | ゲームがウィンドウ表示か。「ゲームのウィンドウを検出」の一覧から選ぶ |
| 大きさを変えられない | 全画面表示でないか。ゲームだけ管理者で動いていないか |
| 丸の位置がずれる | ウィンドウの大きさが 16:9 か。ゲームの画面に別のウィンドウが重なっていないか |
| 思考エンジンに「(見つかりません)」と出る | `engines/` の中の exe がセキュリティソフトに隔離されていないか |
| 「すでに起動しています」 | 2つ目は起動できない。1P・2P はメイン画面で両方選ぶ |
| 動きが重い | ぷよは「CPU の使用」を減らす、「思考エンジンの優先度を下げる」を入れる |
| 落ちる | exe と同じフォルダの `crash_log.txt` を見る |

不具合を知らせる時は、「プラグイン…」でログ出力を有効にし、「認識結果と提案をログに出力する」を入れて再現すると、`debug_logs/` に記録が残ります。
**ログには画面の画像が入ることがあるので、人に渡す前に中を確かめてください。**

## 5. 更新・削除

- **更新** — 新しい zip を別のフォルダに展開し、使い続けたい設定があれば `config/` を写す。
  同梱のエンジンは新しい版のフォルダのものを使います(「変更…」で差し替えたエンジンは、差し替えた先のまま)
- **エンジンだけを新しい版にする** — 「エンジンの登録…」で選んで「変更…」を押す([詳しく](ENGINE_SPEC.md#同梱のエンジンを新しい版に差し替える))
- **削除** — フォルダごと消す。レジストリなど、ほかの場所には何も書きません
